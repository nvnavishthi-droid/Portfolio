# Navishthi N V | Portfolio

**Live site: [navishthi-portfolio.vercel.app](https://navishthi-portfolio.vercel.app)**

Personal portfolio of Navishthi N V, a second-year Computer Science Engineering student at Chennai Institute of Technology and an aspiring Software Development Engineer, focused on Java, AI/ML and full-stack development.

## What's inside

- About, experience, projects, skills, achievements, certifications and education
- Live demo links for projects and coding profile links (CodeChef, LeetCode, SkillRack)
- Downloadable resume
- Light and dark mode
- Scroll animations and 3D hover effects on cards, on desktop and mobile
- Responsive layout for phones, tablets and laptops

## Built with

HTML, CSS and JavaScript. No frameworks or build step. Hosted on Vercel.

## Run locally

```bash
git clone https://github.com/nvnavishthi-droid/Portfolio.git
cd Portfolio
python3 -m http.server 8000
```

Then open http://localhost:8000.
